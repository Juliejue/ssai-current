# 此在 / Current

本轮把一次出门真正接成了一条线：手机和桌面通过 6 位临时会话码同步结构化进度；完成到访反馈后，可以直接生成一份“美的采集者”草稿。“接力社群”沿用原有命名，同时不建主页、不显示昵称、不揭面也不能私信。演示种子不会冒充实时信息，本机草稿不会冒充已发布内容。

在说不清的时刻，帮你找到此刻适合你的空间。

基于 AI 与真实到访反馈的**情绪—空间匹配平台**。SSAI 黑客松项目。

> **此在** = 海德格尔 Dasein，"在此处存在"。不问你是什么样的人，只问你此刻在哪儿。
> **Current** 一词三义：此刻的 / 电流（HRV、皮电）/ 水流。

## 怎么跑

原视觉原型仍可直接双击打开；AI 自然语言、语音和闭环事件需要同时运行后端。

```
双击 此在-current-原型.html
```

### AI 后端开发

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt pytest
.venv/bin/uvicorn backend_app.main:app --port 8001
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/此在-current-原型.html`。

环境变量参照 `.env.example`：

- 未配置大模型时，使用可测试的本地规则解析，不影响开发。
- 配置 OpenAI-compatible 模型后，模型只负责把自然语言转换为受约束的需求结构。
- 配置腾讯云 ASR 后，音频由浏览器直传腾讯；Current 后端只生成两分钟有效的签名。能力探测尚未返回时也先走腾讯，避免大陆用户误用可能不可达的浏览器听写服务。
- 配置高德 Web 服务 Key 后，且地点完成过人工核对时，用户主动授权位置后会使用真实步行距离和时间；否则自动回退到原型估算。
- 配置 PostgreSQL 后，推荐决策、行为事件、到访结果与短时跨设备中继进入闭环数据库；不配置时中继只适合本机单进程联调。
- 原始语音和用户倾诉原文均不写入数据库或分析事件。

运行检查：

```bash
.venv/bin/pytest -q                    # 含红线回归测试集（FR-29）
node --check current-client.js
node --test tests/*.test.js             # 主动触达 + 语音握手/重采样/清理
node scripts/extract_place_data.mjs
```

`tests/test_redline.py` 是 §9 边界的回归网：禁止词（含扫描原型文案）、负向变化不用红、
强痛苦必须转介、追问只问一次、输出契约失败重试一次再兜底、留痕不含原话，
以及四条评委式红队用例。改文案改到越界，这一组会先红。

### 地图地点核对（不自动认领）

原型里的地点名称不能直接当作可靠地图身份。先把 `AMAP_WEB_SERVICE_KEY` 放进本地 `.env`（不要提交），再生成候选：

```bash
AMAP_WEB_SERVICE_KEY=你的服务端Key .venv/bin/python -m scripts.resolve_amap_places
```

候选写入被 Git 忽略的 `backend_app/data/amap_candidates.json`。人工核对名称、地址和坐标后，只把确定的一项写入 `backend_app/data/place_overrides.json`：

```json
{
  "places": {
    "wansheng": {
      "amap": {
        "provider_place_id": "高德POI ID",
        "longitude": 116.0,
        "latitude": 39.0,
        "verified_name": "地图中的正式名称",
        "address": "人工核对后的地址",
        "verification_status": "verified",
        "verified_at": "2026-09-05T00:00:00Z"
      }
    }
  }
}
```

代码不会自动采用搜索第一名；只有 `verification_status=verified` 才会用于路线和导航。

### 闭环数据库

Vercel 上建议从 Marketplace 连接 Neon，并给 `DATABASE_URL` 使用 pooled connection string。环境变量只配置在服务端，按 Development / Preview / Production 分开管理。首次连接后运行：

```bash
.venv/bin/python scripts/migrate.py
.venv/bin/python -m scripts.seed_places
```

数据库保存：结构化需求、推荐排名与得分、接受/拒绝/导航/到访状态、反馈分数和因素、**哪一环对/错**（`mismatch_stage`，FR-09 / SP-4，冷启动 L0 里最有价值的一列）。数据库不保存：倾诉原文、原始语音、用户经纬度；私密反馈正文也不上传。

断网也能跑。手机上看用这个链接（私有，问 Julie 要）：
<https://claude.ai/code/artifact/d78298ab-65f6-4a87-9656-4e1be7a0516b>

### 跨境：开发机和 Vercel 都在境外

调用国内服务时要记住这条。开发机出口在境外，Vercel 也没有中国大陆区域。

- **高德、LLM 是后端调的 → 跨境**。首次连接经常超时，`map_provider` 和
  `interpretation` 都加了传输层重试。别把重试删掉，那不是防御性冗余。
- **腾讯 ASR 是浏览器直传的**。后端只签名、不碰音频；大陆用户优先走腾讯的
  「中国大陆实时流量」。香港、澳门、台湾及其他境外地区属于腾讯的跨境范围：
  未开通时前端自动优先浏览器听写，开通后设置 `ASR_CROSS_BORDER_ENABLED=true`
  即可让两地都优先腾讯。大陆和香港都要真机验证；大陆测试不需要 VPN。

### 主旅程（AI-native，PRD V1.5 §6.4）

第一屏是语音，不是选择题：

```
#/talk   说一句（语音优先，也可以打字）
  ↓      POST /api/v1/interpret
#/echo   小在复述「我猜你更接近…」+ 1–3 条证据 + 至多一次追问
  ↓      【就按这个】／【不太对】→ #/fix 六个身体感受 chips，选完立即重推
#/offer  1 主推 + 2 备选：动作标题 · 状态→需求→命中属性 · 到达成本 · 代价
  ↓      【带我去】→ 行程条（在路上 → 我到了 → 我离开了）
#/visit  30 秒反馈 → #/records 里能看到小在从这些记录学到了什么
```

强痛苦表达在调用模型之前就被规则拦下，直接进 `#/safe`：不推荐空间、不分析、只给人类支持入口。

**只聚合，不展示单条（US-04）**：曾经有一个「匿名到访流」，逐条读别人留下的话。
它被拆掉了——单条一旦露出就变成对空间的评分，而评分可以刷，正是评委 #3 问的那件事。
现在 `#/nearby` 只讲汇总口径和当前样本量；一条真实反馈都没有就老实空着，
不拿原型数据充数。进汇总要同时满足三件事，判据只写在 `countsTowardAggregate()` 一处：
真的去过（核验过的到访，自述不算）、明确选了匿名贡献、且该地点攒够 5 条。

真人原话留下了，但换了身份：它是**空间档案的来源**（FR-16 评论那一路），
不带变化分、不进任何汇总，在详情页里和汇总分开放。

授权文案跟着改了——「匿名分享给需要的人」在不展示单条之后就是假话，
现在写的是「没有人会看到你这一条本身」。

**主动触达（§6.3 路径 A）与守护层（FR-14）**：规则本身在 `reach-policy.js` 里，
是纯函数、有 13 条 Node 测试（`node --test tests/reach-policy.test.js`）——
「不打扰」如果只写在文案里、没写在代码里，它就不存在。日上限、静默时段、
两次之间的最小间隔、连续被拒逐级降频（1→3→7 天，第四次彻底停掉）都在那里。
触达页带「为什么是现在」的证据；手上只有时间这一个信号时就直说「纯属瞎猜」。

**延迟复看（FR-31）**：选「现在不方便」不是拒绝，是改约——记下时间、到点回来**一次**，
中间不追问，之后当晚不再打扰。PRD 原本要对比峰值与当前 HRV，我们没接手表，
就不假装能看出来：问一句，并说明接上之后这一步会自动判断。

**分层授权（M6 / FR-04）**：`#/settings` 只展示已经可用的输入与位置权限，
并写清楚存什么、不存什么。尚未接入的 HRV 等路线图不出现在用户界面。
同页保留本机数据清单和一键清空（本地清完会把服务端那几条一起删）。

**纠错四环（FR-03）**：`#/fix` 让用户指出 **状态 / 需求 / 条件 / 地点** 哪一环不对。
默认停在「状态」，最常见的情况仍然只要一次点击（US-02）；要改别的环才多一次。
选项白名单在服务端（`interpretation.py` 的 `corrections`），条件那一环的 key 是
`字段:值`，改完仍会按 `NeedState` 的字面量重新校验——客户端塞不进白名单以外的值。
「太远了」会真的过滤：`max_travel_minutes` 现在对原型估算也生效，上限太紧导致
一个都不剩时，会放开上限重来一次并明说「这些都超了」（US-03 近处先接住）。

**地图三选（US-06）**：`带我去` 弹出高德 / Apple / Google。我们存的是高德的 GCJ-02，
Apple 和 Google 要 WGS-84，`backend_app/coords.py` 做反向转换——境内偏差 555 米，
不转换就是隔壁街区。和导航、围栏同一道门：没有人工核对过的坐标就一条链接都不给。

**记忆可删除（FR-12 / §M6）**：到访卡上有删除入口，二次确认后本地和服务端同时删除
（`POST /api/v1/outcomes/delete`，按 session_id + recommendation_id 精确匹配）。
服务端删不掉会如实告诉用户，不假装删了。删除日志只记「发生过删除」，不记内容。

**心情轨迹卡（FR-32）**：反馈保存后可生成 1080 × 1350 的 PNG。图片只使用地点、
到访前状态、变化分、因素和停留时间，**不包含用户写下的自由文本**。支持 Web Share API
时会打开手机系统分享菜单，用户可选择系统提供的「存储图像」或已安装的平台；浏览器不支持
图片分享时会自动下载 PNG。网页不能保证某一个社交 App 一定出现在菜单里，因此界面不冒充
朋友圈、小红书或微博的私有直连接口。

**在场证明 L1（FR-08）**：围栏判定整个在浏览器里完成，**围栏过程不会上传用户轨迹**——
只上传「进没进围栏」和「待了多久」。用户主动开定位时，一次性坐标会用于高德周边搜索、
路线与逆地理编码，但不写日志、不入库、不形成轨迹。因此浏览器报的等级不可信，服务端只会往下降级
（`backend_app/presence.py`）：地点没有人工核对过的坐标就没有围栏，任何围栏声明都会被降回
`dwell_only`；停留不足 5 分钟一律降到 `self_reported`，且不进任何地点的匿名汇总。
浏览器定位是 WGS-84、高德坐标是 GCJ-02，境内相差 500 米以上，`current-client.js` 里做了转换——
不要绕过它，否则 150 米的围栏会完全失效。

**精确城市反查**：`POST /api/v1/location/reverse` 调用高德逆地理编码，不再依赖四城矩形判断。
北京、上海、广州、深圳之外的中国大陆城市也能进入附近搜索；四城矩形只在地图服务失败时保底。

**空间画像**：只有服务端核验为 `geofence_dwell` 的到访反馈会进入 `space_profiles`。
同一地点少于 5 次时不参与排序；达到门槛后，也只会以最高 45% 的权重保守修正人工标签。
推荐响应用 `attribute_source=verified_feedback` 和 `sample_size` 明示证据来源。

**匿名共创审核**：社区表单明确区分“只存本机”和“提交审核”。后者进入
`community_contributions` 的待审队列，审核通过才会出现在公开列表；媒体仍只存在本机，
服务端只接收数量。执行 `006_space_profiles_and_community.sql` 后，可用
`.venv/bin/python scripts/moderate_contributions.py --list` 查看待审条目，再以 `--approve ID` 或
`--reject ID` 处理。生产数据库地址通过 `DATABASE_URL` 提供。

**营业状态（FR-07）**：`backend_app/opening_hours.py` 存的是**类目常识**（唱片店一般 12:00–20:00、
club 一般 21:00–04:00、河岸胡同没有门），不是某一家店的一手事实，所以永远标注「未经核对」，
只降权、不硬过滤。要让它变成真正的硬约束，把逐店营业时间人工核对后写进
`place_overrides.json` 的 `hours` 并标 `verification_status: "verified"`——和地图身份同一套纪律。
判断用北京时间（26 个地点都在北京），凌晨只会推「没有门」的地方。

`#/mood → #/needs → #/mode → #/pick／#/browse` 保留为「就是不想说话」的备用入口。

### 跨设备接续

手机在 `#/connect` 生成 6 位会话码，电脑输入后会自动收到“理解完成、推荐、出发、抵达、反馈、匿名采集”六类结构化事件。会话 12 小时后自动失效；原始倾诉、经纬度、私密笔记和身份信息都不会进入中继。生产环境需先执行 `005_relay_sessions.sql` 迁移并配置 `DATABASE_URL`。

## 三条硬边界

**会否决设计方案，不是价值观标语。**

1. **不诊断** —— 不给情绪贴标签，不暗示病理。可以说"你 7 次里有 5 次选了人不多"，不能说"你是高敏感人群"。
2. **不评判** —— 变化分数**负端不能用红**。情绪变差不是错误，只是这次没接住。
3. **不社交** —— 没有昵称、人脸、主页、评论、关注、私信。只有用户主动匿名贡献的记录会露出。

## 一条视觉规则

**冷色承担空间与时间，暖色只标记"你 / 此刻"。**
用色比例 70 底 / 22 墨 / 6 水青 / **2 赭**。一屏之内出现超过两处赭色，就是没改干净。

```
--paper #F0F3F2   --card #FFFFFF   --sunk #E8EDEC
--ink   #122A2E   --ink-dim #5A6E70   --ink-faint #8CA0A0
--water #1E6E72   流 · 空间 · 冷
--sun   #C4703C   此刻 · 你 · 唯一的暖
情绪色阶 −3…+3：#4E4B63 #6B687F #9694A5 #C3C9C7 #86ADA8 #4A8F8A #1E6E72
```

## 一条内容规则

**讲"你到了做什么"，不讲"这个地方是什么"。**
卡片标题是一个动作，地名降为副标题。没有评分、没有必去、没有氛围感，代价照实写。
`会看到什么` 这一行专门用来**替代照片** —— 小众场所没有合规图源，硬配图会错配。

## 注意

- 内含 **7 条真人原话**（群聊摘录，见各地点的 `quote` 字段）。已无人名与私人场景，但仍是他人原话——
  若当事人希望撤下，改成转述即可（搜索 `quote:` 定位）。
- 界面上不会读取 `places.json` 里的原型 `averageChange` / `feedbackCount`。只有数据库中达到 5 次围栏停留核验的真实反馈才可显示样本量并修正画像；不足门槛仍显示「样本还少」。
- 物料里的二维码是占位图形，扫不出东西。
