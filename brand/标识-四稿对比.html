四个方向，先只看骨架

这一轮不看颜色、不看质感，只看形状能不能立住。四稿都是等粗线条的黑白结构稿， 放在同样的白底、同样的尺寸下，是为了让比较是公平的。 整体基调这次是推倒重做的浅色，所以配色会在选定方向之后单独定，不影响这一轮判断。

怎么挑：把注意力放在两件事上 —— 一，它像不像「此在」在做的事（情绪 → 空间 → 此刻）；二，缩到 24px 还认不认得出。

怎么投：在群里回一个字母 A / B / C / D，加一句为什么。可以投两个。也欢迎「都不对，因为……」——那比选一个更有用。

A

点落在流上

a point on the current

一条不急不缓的流，穿过一个围合。它们相交的那一点，就是此在 —— 不是流本身，也不是空间本身，是「你此刻正好在这里」。

  • 线Current —— 时间、心率、江面。持续在走，不停
  • 环空间 —— 沿用原型里「环 = 开阔度」的既有符号
  • 点此在 —— 沿用原型里的光点，落在环与流的交点上
优势中英文名第一次对上同一个形；和产品界面里已有的空间符号系统同源，logo 和 UI 不会像两家公司
风险元素有三个，是四稿里最"多"的，极小尺寸要做减法版

B

被接住的波

the wave, settled

一根线讲完整个产品：左端又急又密，是出发前；往右波长拉长、振幅收窄，最后归于一条微微上抬的平线 —— 那是空间接住你之后。

  • 左段高频 —— 停不下来、坐不住的状态
  • 右段低频 —— 波长变长，起伏变小
  • 末端+ —— 不是回到原点，是略高于原点
优势最直接对上 Current，也最直接对上 HRV / 皮电这条产品主线；动效潜力最大，加载、录入、反馈保存都能用它
风险和「空间」几乎没关系，只讲了情绪那一半；横长比例极端，正方 icon 里必须截断或折行，24px 基本糊掉

C

共用一条地面的「此」

one ground, shared

「此」=「止」+「匕」，本义就是停在这里。这一稿只改一处：把「止」的底横抻长， 一路托住右边的「匕」，让两个部件站在同一条地面上。那条线既是字的笔画，也是台阶、长椅、江堤。

  • 底横一笔两用 —— 同时是「止」的底和「匕」的竖弯钩
  • 字义止 的甲骨文是脚印，这个字自带「到了、停下」
  • 末梢上挑 —— 唯一一处向上，收在离开的方向
优势中文语境最有分量，字标即品牌，不用另配名字；哲学出处（此在／Dasein）在中文里读得懂
风险英文场景完全失效，Current 那半边接不上；24px 下汉字必糊，必须另配一个非字形的 icon —— 等于要做两套

D

留了口的围合

an enclosure that lets you go

一个围合，但四边都没合上，底下那道口子留得最大 —— 这里接住你，不留住你。 中心的点也不在正中，它偏向出口，因为人从来不站在几何中心。

  • 四弧空间 —— 有边界，可停留
  • 缺口可离开 —— 产品不做留存陷阱，随时能走
  • 偏心点你 —— 位置本身是数据，会随记录移动
优势小尺寸最稳，24px 依然清晰；形状最简单、最容易记；「留了口」这个态度和产品的隐私立场是一致的
风险四稿里最冷、最像工具而不像陪伴者；虚线圆这个形被用得很多，独特性最低；和 Current 无关
