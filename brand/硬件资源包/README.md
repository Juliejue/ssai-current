## 硬件专用 · 五件事

### 1. 给激光 / CNC 之前，必须先「轮廓化描边」

SVG 里的环和流线是**描边路径**（stroke），不是填充。很多 CAM 和雕刻软件**会直接忽略线宽**，只认路径中心线——结果就是刻出来的线细得像划痕，或者干脆报错。

动手前在 Illustrator 或 Figma 里执行一次：

- Illustrator：选中 → 对象 → 路径 → **轮廓化描边**（Outline Stroke）
- Figma：选中 → 右键 → **Outline Stroke**

我没有在包里预先转曲，因为转曲之后就不能再改线宽和尺寸了——留给你们按实际工艺决定。

### 2. 最小物理尺寸

主标里最细的就是环和流线，等粗，是整个标识的瓶颈。线宽约等于**标识宽度的 1/97**。

| 工艺 | 该工艺最小线宽 | 主标最小宽度 | 备注 |
|---|---|---|---|
| 丝印 / 移印 | 0.20 mm | **20 mm** | 再小换缩减版 |
| 激光雕刻 | 0.10 mm | **10 mm** | |
| 模内 / 压印 / 蚀刻 | 0.30 mm | **30 mm** | 通常直接用缩减版 |
| **缩减版**（环 + 点） | — | **6 mm** | 背壳、内衬、螺丝盖、表带扣 |

这几个数是按常见工艺极限反推的**起点**，不是承诺。请拿你们供应商自己的 DFM 线宽限制核一遍再定。

### 3. 缩减版什么时候用

流线是最先糊掉的部分。**只要标识宽度小于 10 mm，或者工艺线宽做不到 0.1 mm，就换 `current-mark-reduced`** —— 它只保留环和点，缺口放宽到 70°，线宽加粗，专门为小尺寸重画过，不是把主标缩小。

不要自己去缩主标然后加粗线宽，比例会不对。

### 4. 单色工艺：点仍然是实心的

丝印、激光这类只有一个颜色的工艺，用 `mono` 版本：环、流线、点全部同色。

**点是实心的，环和流线是空心线**——这个对比足够把它读出来，不需要靠颜色。不要为了保住暖色去做二次套印，成本和风险都不值。

### 5. 别放在高曲率的弧面上

丝印和移印在曲率大的地方会拉伸变形，环会变成椭圆。放在平面或近似平面的区域；如果只能放弧面，先打样看变形量。

## 安全边距与禁用

**安全边距**：四周留白 ≥ 环半径的 0.4 倍，约等于**标识宽度的 8%**。这个范围内不要放任何其他元素、螺丝孔、分模线或丝印文字。

**禁用**（这几条会破坏含义，不只是不好看）：

- ❌ 不要把环闭合。缺口是「可以离开」这层意思。
- ❌ 不要填充环。环是空间的边界，不是实体。
- ❌ 不要让环浮空或陷进流线。它们必须**严格相切**——切点是整个标识唯一的交点。
- ❌ 不要让环和流线不等粗。两者是同级的。
- ❌ 不要把点改成冷色。全套视觉里只有它是暖的。
- ❌ 不要旋转。流是水平的。

## 色彩

完整规范见 `04-色彩/色彩规范.txt`。三个关键数：

| | HEX | CMYK（换算值） |
|---|---|---|
| 深青墨 | `#122A2E` | 61 / 9 / 0 / 82 |
| 水青 | `#1E6E72` | 74 / 4 / 0 / 55 |
| 日光赭 | `#C4703C` | 0 / 43 / 69 / 23 |

**没有给 Pantone 编号是故意的。** 屏幕换算出来的 Pantone 号在实体上经常差一到两个色阶，照着做可能白跑一次打样。正确做法是拿上面的 CMYK 让供应商打实体样，再用实体色卡比对定号。

**用色比例 70 / 22 / 6 / 2**——底、墨、水青、日光赭。赭色的稀缺就是它的力量，一个器件面上出现超过两处就该重想。

## 小在（向导）

云朵角色，产品里的 AI 向导。它不是外来的吉祥物——**它是标识里那个环松开之后长出来的**：环坐在流上，小在浮在流上，同一套语言、同样的等粗线条。

四种表情：`xiaozai`（平静，默认）、`xiaozai-look`（看向你）、`xiaozai-closed`（闭眼，记录/私密时）、`xiaozai-with-you`（旁边那个暖点是**你**，不是小在的一部分）。

**只有眼睛，没有嘴。** 有嘴就会有情绪表演，而小在的职责是陪着，不是替你高兴或难过。做实体（贴纸、周边、器件图形）时也守这条。
